# 데이터 테이블 (CSV)

게임의 모든 수치는 `Assets/_Project/Data/Tables/` 의 CSV 7개에 있습니다. 코드를 고치지 않고 표만 바꿔서 밸런스를 조정합니다.

| 파일 | 내용 |
|---|---|
| `zombies.csv` | 좀비 3종 능력치 (체력·속도·공격력·공격 간격·크기) |
| `buildings.csv` | 건물 9종 이름·설명·최대 레벨·비용·건설 시간·생산량 (레벨당 증가율 포함) |
| `hordes.csv` | 대규모 습격 시각과 마리 수 |
| `heroes.csv` | 영웅 8명 — 등급·역할·전투 능력치·내정/정찰 보너스·색·시작 영웅 여부 |
| `troops.csv` | 병종 3개(보병·사수·장갑차) — 능력치, 훈련·치료 비용/시간, 좀비별 상성 배율(`vs_walker` 등) |
| `research.csv` | 연구 13개 — 갈래(경제·군사·방어), 단계, 선행 연구, 레벨당 효과·비용·시간 |
| `balance.csv` | 나머지 단일 수치 전부 — 경제, 밤 난이도, 보상, 웨이브, 영웅 공통·승급, 모집 확률·천장, 스킬, 포탑, 본부, 병영 수용·부상 비율·치료 속도, 연구 감소 상한 |

## 고치는 방법

1. 메뉴 **ZombieSLG ▸ 데이터 테이블 폴더 열기**
2. 엑셀·구글 시트·VS Code 등으로 CSV 수정
   - 엑셀에서 저장할 때는 **"CSV UTF-8 (쉼표로 분리)"** 형식으로 저장하세요. 그냥 "CSV"로 저장하면 한글이 깨집니다.
   - `#` 으로 시작하는 줄은 주석입니다.
   - `balance.csv` 의 `key` 는 코드가 읽는 이름이라 바꾸면 안 됩니다. `value` 만 고치세요.
3. Unity로 돌아오면 **자동으로 가져옵니다** → Console에 `데이터 테이블 가져오기 완료`
4. Play

## 흐름

```
CSV (Data/Tables)  ──저장──▶  에디터 임포터  ──검증 통과──▶  Resources/GameData.asset  ──▶  GameData (런타임)
                                    │
                                    └─ 오류면 Console에 "파일:줄 [열]" 로 표시하고 이전 데이터를 그대로 사용
```

- 런타임에는 CSV를 읽지 않습니다. 임포터가 만든 ScriptableObject(`GameData.asset`)의 행 데이터로 `GameData` 를 만듭니다.
- 검증 항목: 숫자 형식, 최솟값·최댓값, 빠진 행(좀비·건물 종류), 알 수 없는 id, 중복, 빠진 `balance.csv` 키, 습격 시각 순서·밤 길이 초과,
  모집 확률 합계 = 1, 확률이 있는 등급마다 영웅 존재, 시작 영웅 정확히 1명(전투 역할), 역할별 필수 능력치,
  병종 3개 모두 존재, 연구 갈래·효과 이름, 선행 연구 존재·순환 금지·선행이 더 높은 단계가 아닐 것.
- 모집 확률을 바꾸면 게임 안의 **확률 보기** 화면도 표에서 바로 계산되어 함께 바뀝니다.
- 같은 검증이 테스트(`dotnet test tools/DomainTests`)와 CI에서도 돌아서, 잘못된 표는 PR 단계에서 막힙니다.
- **서버에서 바꾸기 (Remote Config)**: 대시보드 Remote Config에 JSON 키 `balance_overrides` 를 만들고
  `{"night.hp_per_night": 0.15, "hq.max_hp": 2600}` 처럼 `balance.csv` 의 키와 숫자를 넣으면, 다음 실행부터 모든 플레이어에게 적용됩니다.
  표 검증(최솟값·최댓값, 확률 합계 등)을 통과하지 못하면 무시하고 CSV 값으로 시작하며, Console에 이유가 나옵니다.

## 새 수치를 추가할 때 (코드 작업)

1. `balance.csv` 에 행 추가
2. 도메인 규칙이면 `GameDataBuilder` 에서 읽고, 화면/전투 쪽이면 `GameDataBuilder.PresentationKeys` 와 `BattleConfig.From` 에 추가
3. 테스트 `EveryBalanceKeyIsUsed` 가 "표에는 있는데 코드가 안 읽는 키"를 잡아 줍니다
